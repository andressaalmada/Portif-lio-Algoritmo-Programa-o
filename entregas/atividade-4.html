Atividade 4 — Listas, vetores e análise de dados

Objetivo: aplicar listas e estruturas de dados para resolver problemas de otimização, análise de materiais e monitoramento de sistemas.

Descrição

Esta atividade abordou casos como vibração em turbina, rota de caminhões, análise de resistências e balanço de massa em reator, utilizando listas e funções auxiliares.

Resultados obtidos

Foi possível desenvolver soluções mais robustas com organização de dados em listas, automação de procedimentos e integração de lógica para tomada de decisão.

Como resolver cada questão

  1. Questão 1 — Média de um conjunto de dados

    Exemplo: para os dados [10, 20, 30], a média é 20.

    Some todos os valores e divida pelo número de elementos para obter a média.

    dados = [12, 18, 14, 20, 16]

media = sum(dados) / len(dados)

print(f"A média dos dados é: {media}")
  2. Questão 2 — Identificação do maior valor

    Exemplo: em [5, 9, 3, 12], o maior valor é 12.

    Use a função de máximo para localizar o maior elemento da lista.

    valores = [8, 14, 6, 21, 10]

maior = max(valores)

print(f"O maior valor é: {maior}")
  3. Questão 3 — Filtragem de valores acima da média

    Exemplo: com [4, 8, 6, 10], a média é 7 e os valores acima dela são 8 e 10.

    Calcule a média e depois selecione apenas os valores que forem maiores do que ela.

    dados = [12, 18, 14, 20, 9, 16]

media = sum(dados) / len(dados)
acima_da_media = [valor for valor in dados if valor > media]

print(f"Média: {media}")
print(f"Valores acima da média: {acima_da_media}")
